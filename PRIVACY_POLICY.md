# Политика конфиденциальности NewsApp

**Последнее обновление:** 6 ноября 2026 г.

## 1. Общие положения

Приложение NewsApp («мы», «наше приложение») уважает вашу конфиденциальность. Настоящая Политика конфиденциальности описывает, какие данные мы собираем, как их используем и защищаем.

## 2. Какие данные собираются

### 2.1 Данные, хранящиеся только на устройстве:
- Список добавленных вами RSS/YouTube/Telegram источников
- Избранные посты (идентификаторы)
- История прочтения (идентификаторы прочитанных постов)
- Настройки приложения (тема оформления, язык)

Эти данные хранятся локально в SharedPreferences на вашем устройстве и **никогда не передаются** на наши серверы.

### 2.2 Данные сетевых запросов:
- При загрузке новостей мы обращаемся к стороннему сервису `api.rss2json.com` для парсинга RSS-лент
- При запросе YouTube-каналов используется `rsshub.app` для конвертации Telegram/YouTube ссылок в RSS-формат

Мы не контролируем политику конфиденциальности этих сторонних сервисов и рекомендуем ознакомиться с их условиями.

## 3. Разрешения приложения

Приложение запрашивает следующие разрешения:
- **INTERNET** — для загрузки новостей из RSS-источников
- **ACCESS_NETWORK_STATE** — для проверки наличия сетевого подключения

Разрешения используются **исключительно** для загрузки контента и не используются для сбора какой-либо информации о пользователе.

## 4. Передача данных третьим лицам

Мы **не продаём, не передаём и не раскрываем** ваши персональные данные третьим лицам.

## 5. Хранение данных

Все пользовательские данные хранятся исключительно на устройстве пользователя. При удалении приложения все данные удаляются автоматически.

## 6. Права пользователя

Вы можете в любой момент:
- Экспортировать свои источники в формате OPML (Настройки → Экспорт)
- Удалить все источники (Настройки → Удалить все источники)
- Очистить кэш и историю прочтения (Настройки → Данные)

## 7. Дети

Наше приложение не предназначено для детей младше 13 лет. Мы сознательно не собираем данные несовершеннолетних.
